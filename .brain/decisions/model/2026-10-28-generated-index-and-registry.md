# Generated index

## Context

The description of a document lives in its frontmatter; a hand-written list of documents in the index would repeat it and risk a discrepancy.

## Decision

- The index of the brain (`README.md`) has a hand-written description of the brain and a generated block `<!-- BEGIN:dotbrain index -->` … `<!-- END:dotbrain index -->` with the list of documents grouped by directory (link and `description`). A conflict in the block is resolved by regeneration.
- It is generated by a tool or by an agent according to the specification.
