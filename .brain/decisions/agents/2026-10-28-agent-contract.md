# Agent contract

## Decision

Core rules: the brain binds, read first, keep to the decisions and update the document in the same change, do not resolve `proposed` decisions, report discrepancies, keep to the step, update the brain. On top of that, rules of language, resolving conflicts and content, and of work in a code repository. There is one contract, and the instruction files of tools are its adapters ([agent-contract.md](../../architecture/agent-contract.md)).
