# Independence from the AI tool

## Decision

No feature of the framework exists in only one tool. Integrations are adapters of one contract: instruction files (`CLAUDE.md`, `AGENTS.md` and others), a context package for chats, plugins and skills ([ai-integrations.md](../../architecture/ai-integrations.md)).
