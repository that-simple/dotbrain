# The dotbrain brain in Polish

## Decision

The documentation of this repository, including everything in `.brain/`, is in Polish. In English are: the specification, the agent contract and the templates of the framework, code, identifiers, comments, log and error messages in code, file and directory names, values in the frontmatter, branch names, commits, PR titles and descriptions. Polish concerns only this brain, not brains created with the framework: the specification and the templates assume no language of the brain.
